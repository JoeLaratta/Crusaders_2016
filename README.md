# The Crusaders Way — 2016 Crusaders

Static site. No build step, no dependencies.

- `index.html` — intro animation (front door)
- `handbook.html` — the program manual
- `favicon.png` — browser tab icon

## Deploy on Vercel

1. Push this folder's contents to the repo root of `JoeLaratta/Crusaders_2016` (branch `main`).
2. In Vercel: **Add New → Project → Import** `Crusaders_2016`.
3. Framework preset: **Other**. Leave build command and output directory blank.
4. Deploy.

Every later push to `main` redeploys automatically.
